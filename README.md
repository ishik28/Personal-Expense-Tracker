### Personal Expense Tracker – Python Project

The Personal Expense Tracker is a menu-driven Python application designed to help students manage and analyse their daily expenses efficiently.

The application allows users to add new expense records by entering the amount, category, date and payment method. All valid records are automatically saved in a text file, ensuring that previously entered data remains available even after the application is closed and reopened.

Users can perform various operations, including:
- **Add Expense:** Record and save new transactions.
- **View Expenses:** Review all previously saved transactions.
- **Total Expenditure:** Calculate the total amount spent.
- **Highest Expense:** Identify the transaction with the highest amount.
- **Category Report:** Analyse expenditure category-wise.
- **Budget Analysis:** Calculate remaining budget or identify overspending.

      

It also incorporates input validation to prevent invalid records from being saved.

**Objective:** To apply fundamental Python programming concepts to develop a practical, data-driven application that simplifies personal expense management.
